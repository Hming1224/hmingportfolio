Before / After component evolution

Before
Repeated layout Each case page rebuilt the same comparison structure.
Hard-coded styles Spacing, borders, and labels drifted across routes.
Regression risk Large AI edits changed visual details that should have stayed stable.
Unclear ownership Story-specific geometry and shared UI rules were mixed together.

The pattern looked reusable, but the abstraction boundary was not yet clear.

After
01
Shared shell Use shared frames for repeated structure and responsive behavior.
02
Route-local story Keep unique narrative geometry colocated with the case route.
03
Token contract Theme color, line, radius, and elevation through stable variables.
04
Small verified batches Every change ends with smoke checks before commit.

The result is reusable where stable, local where story-specific.
