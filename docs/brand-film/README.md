# Hmingportfolio — 30-Second Brand Film

Production package for a 16:9, 30-second English brand film.

## Deliverables

- `01-production-storyboard.md` — shot-by-shot direction and capture requirements.
- `02-asset-inventory.md` — production-backed source inventory and gaps.
- `03-editing-vo-timing.md` — edit decision list, subtitle timing, VO, music, and mix notes.
- `assets/captures/` — verified 1920×1080 website captures generated from the local portfolio.
- `assets/clips/` — short browser recordings and selected existing product clips.

## Editorial rules

- Use only production-backed portfolio screens and source assets.
- Keep the interface legible; avoid cuts shorter than 8 frames unless used in the opening problem montage.
- Preserve the portfolio’s white, ink, and purple visual identity.
- Do not present placeholder or invented Web3 interfaces as shipped work.
- Master at 1920×1080, 30 fps, Rec.709, with a 48 kHz audio timeline.

## Current source limitation

The Web3 project is represented by a production homepage card and two cover assets only. Until original interface exports are supplied, the 0:17–0:21 section uses the real card/cover plus a typographic `Issue → Hold → Verify` sequence. It must not imply that unseen interface screens are available.
